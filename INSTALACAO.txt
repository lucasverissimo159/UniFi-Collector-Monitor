═══════════════════════════════════════════════════════════════
  MÉTODO 1: Instalação Automatizada (Recomendado)
═══════════════════════════════════════════════════════════════

1. Extrair o arquivo:
   
   tar -xzf unifi-collector-monitor.tar.gz
   cd unifi-collector-monitor

2. Executar script de instalação:
   
   bash setup.sh

3. Configurar via Interface (NOVO v2.1):
   
   python3 run.py
   └─ Vá em "⚙️ Configurações"
   └─ Edite Host, Usuário e Senha
   └─ Clique "💾 Salvar"

4. Pronto! Sistema configurado e operacional ✅

═══════════════════════════════════════════════════════════════
  MÉTODO 2: Instalação Manual
═══════════════════════════════════════════════════════════════

1. Extrair e entrar no diretório:
   
   tar -xzf unifi-collector-monitor.tar.gz
   cd unifi-collector-monitor

2. Instalar dependências:
   
   pip3 install PyQt5 requests urllib3

3. Executar:
   
   python3 run.py

4. Configurar via Interface:
   
   Aba "⚙️ Configurações" → Editar → Salvar

═══════════════════════════════════════════════════════════════
  CONFIGURAÇÃO PELA INTERFACE (NOVO v2.1 - RECOMENDADO!)
═══════════════════════════════════════════════════════════════

NÃO PRECISA MAIS EDITAR ARQUIVOS! 🎉

1. Execute a aplicação:
   
   python3 run.py

2. Vá na aba "⚙️ Configurações"

3. Edite os campos:

   │ 🌐 Host:                            │
   │ https://203.0.113.1:8443          │
   ├─────────────────────────────────────┤
   │ 👤 Usuário:                         │
   │ admin                               │
   ├─────────────────────────────────────┤
   │ 🔑 Senha:                           │
   │ ••••••••                            │
   └─────────────────────────────────────┘

4. (Opcional) Clique "🔌 Testar Conexão"

5. Clique "💾 Salvar Configurações"

═══════════════════════════════════════════════════════════════
  SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════

❌ "Erro de conexão UniFi"
   → Vá em "⚙️ Configurações"
   → Clique "🔌 Testar Conexão"
   → Corrija credenciais se necessário
   → Verifique se Controller está acessível

❌ "ModuleNotFoundError: No module named 'PyQt5'"
   → Execute: pip3 install PyQt5

❌ "python3: command not found"
   → Instale Python 3.7+
   → Linux: sudo apt install python3
   → Windows: Download em python.org

❌ "Tabela vazia"
   → Verifique credenciais em "⚙️ Configurações"
   → Confirme que Controller está acessível
   → Verifique se há coletores com "coletor" no nome
   → Veja logs no terminal

❌ "Configurações não aplicam" (v2.1)
   → Certifique-se de clicar "💾 Salvar"
   → Verifique se unifi_config.json foi criado
   → Vá em "🖥️ Monitor" e clique "🔄 Coletar"

❌ "Texto cortado nas tabs"
   → Edite app/gui/main_window.py (linha ~55)
   → Mude: padding: 10px 60px;
   → Adicione: min-width: 250px;
